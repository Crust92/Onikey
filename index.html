Kho APT của Onikey — bộ gõ tiếng Việt cho Linux.

Cài đặt (Ubuntu/Debian):

  curl -fsSL https://xtcrust.github.io/Onikey/onikey-archive-keyring.gpg \
    | sudo tee /usr/share/keyrings/onikey-archive-keyring.gpg >/dev/null
  echo "deb [signed-by=/usr/share/keyrings/onikey-archive-keyring.gpg] https://xtcrust.github.io/Onikey stable main" \
    | sudo tee /etc/apt/sources.list.d/onikey.list
  sudo apt update
  sudo apt install onikey          # bộ gõ cho IBus (GNOME)
  sudo apt install fcitx5-onikey   # addon cho Fcitx5 (KDE...)
  ibus restart                     # hoặc đăng xuất rồi đăng nhập lại

Rồi thêm nguồn nhập: Settings → Keyboard → Input Sources → + → Vietnamese → Onikey

Từ đó về sau: sudo apt update && sudo apt upgrade là lên bản mới.
Mã nguồn: https://github.com/XTCRust/Onikey
